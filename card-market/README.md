# 小牛马 Plus版充值页

## 发布到 GitHub Pages

1. 登录 GitHub，创建一个新的公开仓库，例如 `xiaoniuma-pay`。
2. 上传本目录中的全部文件：
   - `index.html`
   - `recharge.html`
   - `recharge.css`
   - `recharge.js`
   - `alipay-qr.jpg`
3. 进入仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择：
   - Source：`Deploy from a branch`
   - Branch：`main` / `/ (root)`
5. 保存，等待几十秒。

访问地址通常是：

`https://你的GitHub用户名.github.io/仓库名/`

注意：收款码图片文件名必须保持为 `alipay-qr.jpg`，并和 `index.html` 放在同一目录。
